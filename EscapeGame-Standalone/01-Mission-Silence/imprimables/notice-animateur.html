NOTICE ANIMATEUR — MISSION SILENCE

Station acoustique : les enfants cherchent des indices en silence, découvrent le mot à taper (SILENCE par défaut), obtiennent un code 4 chiffres et le notent sur leur fiche. Un bruit trop fort déclenche un avertissement « CHUUUT ! » ; un cri très fort fait « exploser » l'écran (alarme + −20 s).

1. Démarrage

  1. Brancher le micro USB, le placer à mi-salle sur un support stable, loin des bouches d'air.
  2. PC sur secteur ; désactiver la mise en veille et les sons système.
  3. Ouvrir un terminal dans le dossier : node server.js
  4. Ouvrir http://localhost:3000 (Chrome, Edge ou Firefox), autoriser le micro, plein écran (F11).
  5. Calibrer (F8 → « Calibration du micro ») : choisir une référence — bruit de fond au calme (30 dB), un claquement de mains (90 dB) ou un calibrateur 94 dB. Le réglage est enregistré sur le serveur et réutilisé aux lancements suivants ; un bandeau rouge rappelle s'il n'a pas été fait.
  6. Téléphone de l'animateur (même WiFi) : http://IP-du-PC:3000/admin (PIN = adminPin de config.json).

2. Déroulé d'une session (~10-15 min)

  1. Briefing à la porte : mission + « le bruit fait disparaître le code » (affiche poster-porte).
  2. Démo (F10) : taper des mains, chuchoter, crier → lire les dB à l'écran. (2 min, pédagogique.)
  3. F9 (ou bouton Armer du téléphone) : compte à rebours, la recherche commence.
  4. Bruit ≥ seuil = message « ATTENTION… CHUUUT ! » (aucune pénalité, le jeu continue).
  5. Cri ≥ seuil d'explosion = écran brouillé + alarme sonore et −20 s ; la mission reprend toute seule.
  6. Code trouvé = affiché 2 min : les enfants le notent sur la fiche-code.
  7. Échap (ou Stop) : retour à l'écran de repos pour le groupe suivant.

3. Raccourcis clavier (PC) et télécommande

Touche / boutonAction
F8Panneau animateur (calibration, seuils, code, mot)
F9Armer / relancer la mission
F10Mode démo (aucun échec possible)
ÉchapRetour à l'écran de repos
TéléphoneArmer / Relancer, Démo, Stop, seuils ±1 dB, code de session ; vibration à l'explosion

4. Réglages recommandés

  • Seuil d'alerte : 55 dB (conversation = 60 dB déclenche « CHUUUT ! », sans pénalité).
  • Seuil d'explosion : 65 dB (cri/applaudissement → écran brouillé, alarme et −20 s).
  • Code de session : changez-le pour chaque groupe (4 chiffres).
Conseil : testez le seuil en conditions réelles avant l'arrivée des enfants : un adulte chuchote à la porte, un autre tape des mains au fond. Ajustez avec ±1 dB si besoin.

5. Checklist d'installation

  • Micro USB branché et positionné à mi-salle
  • Écran visible de la porte, plein écran
  • Calibration faite (silence + claquement)
  • Télécommande testée sur le téléphone
  • Affiche échelle dB collée dans la salle
  • Briefing collé à la porte
  • 4 indices cachés (rébus, mot, avertissements)
  • Fiches code imprimées pour les enfants
  • Essai à blanc complet effectué
Presque silencieux : le seul son de l'application est l'alarme jouée quand le seuil d'explosion est franchi. Réglez le volume du PC en conséquence et désactivez les autres sons (frappe clavier, notifications système).
