MISSION SILENCE

Votre objectif : récupérer le code à 4 chiffres de la station acoustique. Le code s'affichera sur l'ordinateur, au fond de la salle.
ATTENTION : le système détecte le moindre bruit. Si le bruit est trop fort, le code disparaîtra POUR TOUJOURS !
  • Cherchez les indices cachés dans la salle.
  • Lisez, réfléchissez, chuchotez.
  • Communiquez par gestes, pas par la voix.
  • Marchez sur la pointe des pieds.
Une seule règle d'or : LE SILENCE.
